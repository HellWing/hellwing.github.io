# Repository instructions for coding agents

- Inspect the actual repository files, branch, revision and working tree before making changes.
- Preserve existing user changes and work on a dedicated development branch. Obtain explicit approval before merging or deploying.
- Use verified source material for academic information and scientific achievements. Preserve bibliography citation identifiers and public asset paths.
- Keep confidential information and credentials outside this public repository.
- Run the complete Quarto render and relevant regression tests before reporting completion. See [CONTRIBUTING.md](CONTRIBUTING.md) for the commands.
- Distinguish tested results from assumptions and report all known failures and limitations.
- Keep generated `_site/` and `.quarto/` files out of commits.
